# To-Do List App con React, TypeScript y Context API

Aplicación de lista de tareas que consume datos de una API externa, con soporte para filtros, persistencia y modo oscuro.

## 🧠 Tecnologías usadas

- **React** + **TypeScript**
- **Vite** (build tool)
- **Context API** (manejo de estado global)
- **Tailwind CSS** (estilos y diseño responsivo)
- **LocalStorage** (persistencia)
- **API externa:** https://jsonplaceholder.typicode.com/todos?_limit=10

## ✅ Funcionalidades

- Obtener tareas desde una API externa.
- Mostrar tareas en la interfaz.
- Marcar tareas como completadas o pendientes.
- Eliminar tareas de la interfaz.
- Filtrar por: Todas | Completadas | Pendientes.
- Guardar tareas y filtro en localStorage.
- Modo claro/oscuro con persistencia.
- Estilos responsivos con Tailwind CSS.

## 🚀 Ejecutar el proyecto

npm install    # Para instalar las dependencias
npm run dev    # Para ejecutar el proyecto en desarrollo
npm run build  # Para crear la versión de producción del proyecto
